# Что нового

Раздел `## X.Y.Z` каждой версии показывается в лаунчере при наведении на номер версии
и уходит в описание релиза и ленту автообновления. Пишите пункты для игроков, не для разработчиков.

## Не выпущено
- При запуске лаунчер сам проверяет и ставит обновление; кольцо на заставке показывает ход загрузки, а «Пропустить» откладывает его до следующего раза
- Кнопка «Обновить до …» в заголовке открывает ту же заставку
- После обновления портативная версия и запуск по ссылке на сервер открываются как прежде, без экрана установки
- Новая иконка в стиле интерфейса. Если на ярлыках осталась старая — Windows обновит кэш иконок со временем

## 0.2.2
- Наведите на номер версии в заголовке — появится список изменений
- Кнопка проверки обновлений рядом с версией; лаунчер и сам проверяет их раз в полчаса
- Окна игры и лаунчера открываются там, где вы их оставили, — на том же мониторе и того же размера
- F11 в игре — полный экран без рамки
- В настройках появилась очистка кэша игры: помогает, когда после обновления модулей видны старые или битые файлы
- Защита: страницы, открытые из игры (например, ссылки из чата), больше не могут менять настройки клиента и адрес сервера
- Проверка статуса серверов быстрее и расходует меньше ресурсов

## 0.2.1
- Новый облик пульта: фактурная панель, рифлёная ручка, индикатор с историей FPS
- Ограничение FPS до 240 — числом, фейдером или кнопками 60 / 144 / 240
- Ручка пульта встаёт в «Ручной», когда настройки изменены вручную; пресет сбрасывает правки, а «Ручной» их возвращает
- Авторазрешение учитывает частоту монитора и не принимает её предел за просадку

## 0.2.0
- Собственный установщик: выбор папки, ярлыки, удаление через «Приложения» Windows
- Автообновление из релизов GitHub с проверкой подписи
- Кружок слота показывает, запущен ли сервер, и сам обновляется, пока лаунчер открыт
- Оптимизация работает и во втором окне игры (Sqyre, всплывающие окна)
