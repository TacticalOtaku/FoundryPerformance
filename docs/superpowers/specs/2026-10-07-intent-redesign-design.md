## 1. Решения пользователя

- Основной стиль — Tactile как в AIM 1.8.0; главный экран — вариант «Намерение».
- Подход **C**: токены — дословная копия AIM, примитивы — свои Svelte-компоненты со scoped-стилями.
  GSAP не подключаем; движение — Svelte actions на Web Animations.
- Видеокарта — «FLC, но честно»: значок в шапке с двумя строками («WebGL2», «Аппаратное ускорение»).
  DXGI, `classify_renderer`, отчёт агента о GPU и паспорт удаляются. Автооткат ANGLE при раннем
  `webglLost` остаётся.
- Профиль при первом запуске — всегда «Баланс».
- В объёме все пять экранов: главный, «Настройка», редактор слота, установка, удаление.
  Подпроект 4 сужается до окна обновления.
- Работа идёт в новой ветке `feat/intent` от `main`; из `feat/tactile-redesign` переносятся файлы,
  а не коммиты. Незакоммиченный фикс фокуса окна убран в stash и будет удалён.
- Лишние ветки удаляются последним шагом, после подтверждения списка.
- RU основной язык, EN равноправный: каждая новая строка — в оба словаря.

### 3.4 Движение

`src/lib/motion.ts` — Svelte actions на Web Animations.

- Кривые: `TACTILE = cubic-bezier(0.32, 0.72, 0, 1)`; `SETTLE` — CSS `linear()` из ~24 точек,
  снятых с кривой AIM `M0,0 C0.18,0.9 0.3,1.04 0.52,1.02 0.7,1 0.84,1 1,1` (перелёт ≈ 4 %).
  Точки снимаются один раз скриптом и лежат константой; тест проверяет начало 0, конец 1 и пик 1.02–1.05.
- Длительности: 160 / 240 / 380 / 700 ms (micro, short, base, long).

| Action | Когда | Как |
|---|---|---|
| `openWindow` | монтирование экрана | корень 0.965 → 1 и 10 px вверх, 700 ms `SETTLE`; зоны `[data-part]` всплывают на 10 px с шагом 40 ms, 450 ms `TACTILE` |
| `press` | нажатие кнопки | вниз — 0.96 и 1 px за 120 ms; отпускание (`pointerup`, `pointerleave`, `pointercancel`) — возврат за 450 ms `SETTLE` |
| `rise` | смена ключа (имя сервера) | новое значение всплывает на 6 px из прозрачности, 380 ms `TACTILE` |
| `countTo` | смена числа FPS | счёт от старого значения за 700 ms `TACTILE`, целые |

- Уменьшенное движение — только системный `prefers-reduced-motion: reduce`: `openWindow` и `rise`
  сводятся к прозрачности за 150 ms, `press` и `countTo` отключены (число ставится сразу).
- Анимация перехватываема: новый вызов отменяет старую (`animation.cancel()`), клик не ждёт конца.
- Страховка 2,2 s: если анимация появления не завершилась (окно скрыто, кадры не идут), стили
  снимаются принудительно и окно остаётся непрозрачным.
- Бесконечных циклов нет. В простое лаунчер не рисует кадров.

## 4. Видеокарта: «FLC, но честно»

### 4.1 Проба

`src/lib/gpu.ts`:

```ts
export interface GpuProbe { webgl2: boolean; hardware: boolean }
export function probeGpu(doc: Document = document): GpuProbe
```

- `webgl2` — `canvas.getContext("webgl2")` вернул контекст.
- `hardware` — второй холст, `getContext("webgl2", { failIfMajorPerformanceCaveat: true })` вернул
  контекст. Программный рендер (SwiftShader, WARP) Chromium отклоняет.
- Оба контекста освобождаются через `WEBGL_lose_context`, холсты в DOM не попадают.
- Проба запускается один раз при загрузке лаунчера; результат — в сторе `app.gpu`.
- Ограничение (пишется в комментарии к функции): это проба WebView самого лаунчера с бэкендом
  ANGLE по умолчанию; с игровым окном совпадают только драйвер и видеокарта, выбранный в «Настройке»
  бэкенд ANGLE здесь не проверяется.

### 4.2 Значок в шапке

`IconButton` со значком чипа; цвет значка:

| Состояние | Цвет |
|---|---|
| `webgl2 && hardware` | `--tc-good` |
| `webgl2 && !hardware` | `--tc-warning` |
| `!webgl2` | `--tc-danger` |

Подсказка (`Tooltip`) — две строки с точкой статуса: «WebGL2 есть / нет», «Аппаратное ускорение
есть / нет». Если ускорения нет — третья строка «Обновите драйвер видеокарты и проверьте, что
аппаратное ускорение не выключено в Windows». Если нет WebGL2 — «Foundry не запустится без WebGL2:
обновите драйвер видеокарты». `aria-label` повторяет первые две строки.

### 4.3 Что удаляется

| Слой | Удаляется |
|---|---|
| Rust | `gpu.rs` целиком; фича `Win32_Graphics_Dxgi` в `Cargo.toml`; `AppState.adapters`; команды `classify_renderer`, `classify_launcher`; `gpu_check_current`; `Verdict`, `GpuCheck`, `Settings.gpu_check`; поля `StateDto.gpu`, `gpu_check_current`, `recommended`; `telemetry::Report::Gpu`, `apply_gpu`, `Effects.fallback` |
| Агент | `agent/src/gpu.ts` + тест; `{ kind: "gpu" }` в `bridge.ts` и его тесты; `verdictMessage` и вызов в `main.ts`; строки этого предупреждения в `agent/src/i18n.ts` |
| Фронт | `accel.ts` + тест, `gpu-probe.ts` + тест, `launcherVerdict` и `classifyRenderer` в сторе и `api.ts`, `Verdict`/`GpuCheck` в `types.ts`, параметр `?accel=` и `classify_renderer` в `mock.ts` |
| i18n | `accel.*`, `gpu.*`, `notice.softwareRender`, `unit.gb` (если больше не нужен) |

Профиль по умолчанию в `store.load_settings` — константа `ProfileId::Balance`.

### 4.4 Что остаётся

`Report::WebglLost { early: true }` → `settings.engine.angle = angle.next()` + уведомление
`notice.engineFallback`; защита `session_fallback_done` (не больше одного отката за сессию) — без
изменений.

### 6.4 Последний запуск

- `Settings.last_server: Option<String>` (`#[serde(default)]`). Rust записывает id сервера при
  каждом успешном старте игрового окна. Удаление сервера с этим id обнуляет поле.
- При загрузке выбирается `last_server`, если он есть в списке, иначе первый сервер.
- Чистая функция `intentReason(selectedId, lastServer)` → `"last" | "manual" | null` (покрывается тестом).

### 6.5 Клавиатура

Порядок фокуса: шапка → `Segments` профиля → «ЗАПУСК» → строки серверов → «Добавить сервер» →
карточка. Стрелки в `Segments` — `radio.ts` («РУЧ» только мышью). Enter на строке выбирает её,
повторный Enter запускает.

## 9. Установка и удаление

### 9.1 Установка (`InstallScreen`)

Шапка без GPU и «Настройки». Тело — `Shell` на всю ширину, две колонки `minmax(0, 1.2fr) minmax(0, 1fr)`.

- Слева: заголовок Unbounded 700, 28 px («Установка Foundry Performance» / «Обновление до X» /
  «Уже установлено»); лид; поле папки — `Field` + `Button` «Обзор», ошибка под полем;
  `Toggle` «Ярлык на рабочем столе», `Toggle` «Запустить после установки».
- Справа: `Tray` с шагами «Проверка / Копирование / Ярлыки / Регистрация» — у каждого точка
  (ждёт — полая `--tc-muted`, идёт — акцент со свечением, готово — `--tc-good`, ошибка — `--tc-danger`
  и текст ошибки под шагом); под лотком `Band` общего прогресса и процент моно.
- Внизу левой колонки `Primary lg` «Установить» / «Обновить»; после успеха — «Открыть Foundry
  Performance»; при ошибке — «Повторить».
- Состояние «Уже установлено»: лид с версией и папкой, действие — «Открыть установленную».

### 9.2 Удаление (`UninstallScreen`)

`Shell` по центру, ширина 480 px: заголовок, лид, `Toggle` «Удалить настройки и статистику»
(подпись прямым текстом, что это необратимо; включённый тумблер — цвет `--tc-danger`);
`Button` «Отмена» и `Primary sm tone=danger` «Удалить». Во время работы — `Band` и строка статуса;
в конце — «Готово» и «Закрыть».

## 12. Доступность и производительность

- Контраст текста ≥ 4,5 : 1, крупного текста и границ контролов ≥ 3 : 1 в обеих темах и на всех
  10 акцентах (токены AIM уже проверены; проверяем новые сочетания: точки статуса, `Toggle`, `Swatches`).
- Фокус — кольцо акцента 2 px по `:focus-visible`; у каждой кнопки-значка `aria-label`.
- Все состояния интерактивных элементов: покой, наведение, фокус, нажатие, выбран, отключён,
  загрузка, ошибка, пусто.
- Анимируются только `transform`, `opacity`, цвета через `@property` и ширина шкал;
  `backdrop-filter` и `filter: blur` не используются.
- Лаунчер в простое держит ≈ 0 % GPU (сумма по дереву процессов `msedgewebview2`).
